# НЕ СТУДИЯ ЗВУКОЗАПИСИ — Project Overview

## Суть проекта
Одностраничный продающий лендинг для атмосферной студии звукозаписи в Иваново.
Название бренда: **НЕ СТУДИЯ ЗВУКОЗАПИСИ** — провокационное, запоминающееся, работает как хук.

## Бизнес-цель
Конвертировать посетителя в запись на:
1. **Пробное занятие** — "Запиши свой первый трек" (1000 ₽)
2. **Курс** — "Сведи свой трек сам" (9900 ₽)

## Целевая аудитория
- Возраст: 16–35 лет
- Интересы: современная музыка (hip-hop, indie, electronic, pop)
- Уровень: новички и музыканты среднего уровня
- Боли: "хочу записать трек, но не знаю как", "записывал — получилось плохо", "не умею сводить"

## Секции лендинга (порядок)
1. **Hero** — Заголовок + атмосфера + CTA
2. **Для кого** — Боли аудитории (stagger cards)
3. **Что получите** — Результаты с иконками
4. **Услуги** — 2 продукта с ценами и CTA
5. **О студии** — 3 фото + описание
6. **Footer** — Контакты + ссылки
