## Технические заметки

**Производительность:**
- Шрифты через `font-display: swap`
- Изображения в WebP + fallback JPG
- Анимации через `will-change: transform` для GPU
- IntersectionObserver вместо scroll event

**Браузерная поддержка:**
- Chrome 90+ ✓
- Firefox 90+ ✓  
- Safari 14+ ✓
- Edge 90+ ✓
- IE — не поддерживается

**Приоритет разработки:**
1. Мобильная версия (большая часть аудитории)
2. Desktop enhancement
3. Анимации как прогрессивное улучшение
